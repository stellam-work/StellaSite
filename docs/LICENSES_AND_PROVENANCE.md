# Licences and Provenance

## Runtime code

The prototype adds no third-party JavaScript or CSS dependency. The raw WebGL implementation uses browser platform APIs only.

## Supplied site media

The shoreline posters and video files were copied from the user-supplied `hello-this-is-me-webgl-prototype-v5.2` package. No external source or licence statement accompanied them. They are treated as owner-supplied material for this prototype; public redistribution rights were not independently verified.

## Character assets

The final 75 transparent cartoon PNG frames, master image, contact sheet, pose map, and clip guides came from the user-supplied `stella-75-poses(1).zip`. Its README states that the poses were individually generated against a locked character master, aligned to a shared foot pivot without mirroring, and assembled with Pillow.

The original 1536 x 2048 RGBA PNGs are retained unchanged as editable sources. Alpha-enabled 960 x 1280 WebP runtime derivatives were created locally without cropping, background removal, or pose changes.

No separate public licence or attribution requirement accompanied the character package. It is treated as owner-supplied material. Approval for public deployment and redistribution remains with the owner.

## Fonts

The site uses system Arial/Helvetica and Courier New/Courier stacks. No font files are bundled.
